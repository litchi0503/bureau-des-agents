# Les versions

## À venir

- Reprendre une mission terminée (missions précédentes et carnet) : la séance de Max se rouvre. Si elle n'existe plus, le bureau propose une nouvelle demande avec le contexte.
- Les réponses Telegram (1A, OK, KO, oui, non) vont à la mission qui a posé la question, même terminée.
- Dans un projet, chaque demande a son dossier dans Projets/<projet>/demandes/, et Max lit la carte et le rapport de la précédente.
- Le hook laisse passer la lecture seule sans question, demande la permission (une fois, pour la demande, non) pour docker, les bases, sudo, ssh, le réseau, les suppressions hors du projet, un nouveau paquet, un autre push ; chaque refus donne son alternative.
- Moins de jetons : contre-relecture seulement sur un écart bloquant ou moyen dans du code, un seul rapport.md de 15 lignes, Sonnet pour le rangement, les docs et git.
- Les agents d'une demande coupée par un redémarrage passent à « Interrompu ».
- Enchaîner les demandes du carnet (interrupteur sur la fiche du projet).

## v0.1.0 (14 octobre 2026)

La première version publique.

- Max, le chef de projet, et son équipe de vrais sous-agents Claude Code : recherche, code, design, rédaction, analyse.
- Le bureau en pixel art, dessiné en code : les robots vont à leur poste, et chaque bulle montre ce qu'ils font vraiment.
- Les rapports, les fichiers rendus, les sites créés affichés dans un écran (ordinateur ou téléphone), le code et ses versions.
- Le plan au tableau et son historique, toute l'équipe et ses outils, l'historique des agents passés au bureau.
- Rejouer une mission sans relancer l'équipe, une démo hors ligne.
- Le mode tournage (caméra automatique, cadre vertical), la visite guidée avec la voix de Max, le jukebox, et quelques surprises.
